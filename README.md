# 영어뇌 랩 (English Brain Lab)

라이브 아카데미 스타일의 영어 뇌 트레이닝 PWA. 한국어 상황을 먼저 보고 직접 영어로 말한 뒤,
핵심 문장의 뉘앙스 해설 → 변형 패턴 드릴 → 랜덤 복습으로 굳히는 4단계 학습 흐름을 제공합니다.

- 6개 챕터 · 66개 유닛 · 100+ 추가 표현
- Web Speech API TTS (1.0x / 0.8x / 아주 느리게) · STT 발화 채점
- 학습 진도·연속 학습·14일 기록, localStorage(`liveacademy.v1`) 저장, JSON 백업/복원
- 오프라인 지원(Service Worker, 빌드 해시 캐시)
